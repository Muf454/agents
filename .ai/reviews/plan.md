- P1: **T007 `--revision` — "keep DONE tasks, their status and results unchanged" is prompt-only, unenforced and untested** (suspected, high impact). T007 gives the planner `Write(./.ai/tasks.md)` (whole-file replacement) and the host only runs `plan-scope` and `tasks check` afterwards (`.ai/tasks.md:389-391`). `tasks()` (`scripts/lib/workflow.py:418-455`) accepts any queue where DONE tasks have DONE dependencies; it cannot notice that T001–T005's DONE blocks and results vanished or were flipped to TODO. Plan change: add to T006 a helper `plan-keeps-done START` (DONE task IDs in `git show START:.ai/tasks.md` must still exist with `Status: DONE` in the working tree; failure names the ID), call it in T007 after the session when `--revision` is set (`ai_die "Planning: DONE task T00x was changed or removed"`), add mock mode `plan-revision-drops-done` and a test `test_plan_session_revision_keeps_done_tasks`.
